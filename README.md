Đây là bài tập lớn học phần Kỹ thuật lập trình nâng cao của nhóm 8.
Gồm các thành viên:
1.Nguyễn Thị Thùy Dương
2.Nguyễn Trương Minh Thơ (Nhóm trưởng)
3.Nguyễn Thị Kiều Trang
4.Nguyễn Hữu Trí
Nhóm chúng em thực hiện đề tài là: Xây dựng phần mềm quản lý Siêu thị.
Gồm các chức năng chính là:
1. Quản lý nhân viên
2. Quản lý khách hàng
3. Quản lý hàng hóa / kho hàng
4. Quản lý hạn sử dụng
5. Bán hàng
6. Báo cáo và thống kê
7. Lưu trữ dữ liệu
8. Đăng nhập và phân quyền
Hướng dẫn sử dụng phần mềm quản lí siêu thị:
Vào phần mềm quản lí siêu thị -> Đăng nhập mã NV và mật khẩu -> Chọn các chức năng trên giao diện chính của phần mềm như: tổng quan, tra cứu hàng hóa, quản lí kho, bán hàng và báo cáo.
